# Kello Kickstarter project #
[Kickstarter page](https://www.kickstarter.com/projects/8220280/kello-the-sleep-revolution-device-that-upgrades-yo)  
In 2016, I designed the electronics boards for Kello.  
Kello is a smart alarm clock project that was successfully funded on Kickstarter.  
Unfortunately this project was discontinued due to a lack of funding.  
With the permission of the founders, I release here some of the design files and documents.  
10 years on, there are still some Kello users and this may help them troubleshoot their devices.
